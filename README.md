# پورتفولیوی مصطفی یقین — React + Vite + React Router (فارسی / انگلیسی)

یک سایت پورتفولیوی چندصفحه‌ای با دو زبان (فارسی راست‌به‌چپ و انگلیسی چپ‌به‌راست).
پروژه‌های گیت‌هاب را خودکار از حساب GitHub می‌خواند.

## اجرا (فقط سه دستور)
```
npm install      ← فقط بار اول (کمی صبر کنید تا کامل تمام شود)
npm run dev      ← سایت روی http://localhost:5173 باز می‌شود
npm run build    ← ساخت نسخه نهایی در پوشه dist
```
اگر خطای نصب دیدید: پوشه node_modules را پاک کنید، دوباره `npm install` بزنید و پروژه را در یک پوشه کوتاه مثل C:\portfolio بگذارید.

## کجا چه چیزی را عوض کنم؟
| می‌خواهم... | فایل |
|---|---|
| لینک واتساپ، تلگرام، گیت‌هاب، شماره و آیدی | `src/data.js` (بخش SOCIALS) |
| متن‌های فارسی و انگلیسی سایت | `src/data.js` (بخش TEXT) |
| پروژه‌ها و عکس پروژه‌ها | `src/data.js` (بخش PROJECTS) |
| رنگ‌ها و ظاهر | `src/style.css` |
| عکس خودم / لوگو | `public/photo.jpg` و `public/logo.jpg` |

## عکس پروژه‌ها
- پروژه‌های بخش «پروژه‌های من»: عکس را در `public/images` بگذارید و در `src/data.js` جلوی `image` بنویسید، مثل `"./images/erp.png"`.
- پروژه‌های گیت‌هاب: داخل خود مخزن یک فایل به نام `screenshot.png` بگذارید. سایت خودش آن را نشان می‌دهد.

## ساختار پوشه‌ها (ساده)
```
src/
  main.jsx            ورودی برنامه (HashRouter را اینجا می‌گذاریم)
  App.jsx             زبان، مسیرها (Route) و چیدمان کلی
  data.js             همه متن‌ها و لینک‌ها
  Icons.jsx           آیکون‌ها
  style.css           همه استایل‌ها
  components/         تکه‌های تکراری: Header, Footer, ProjectCard, ScrollToTop
  pages/              هر صفحه یک فایل: Home, About, Projects, GitHub, Contact, NotFound
```

## چطور صفحه تازه اضافه کنم؟
1. یک فایل در `src/pages` بسازید (مثلا `Blog.jsx`).
2. در `src/App.jsx` یک خط `<Route path="/blog" element={<Blog t={t} />} />` اضافه کنید.
3. در `src/data.js` داخل `nav` هر دو زبان یک مورد تازه بگذارید.

## نکته‌هایی برای مصاحبه (چه چیزهایی در این پروژه هست)
- **React Router (v6):** چند صفحه با `Routes`، `Route`، `Link` و `NavLink` (صفحه فعلی در منو مشخص می‌شود) و یک صفحه NotFound.
- **کامپوننت و props:** هر بخش جدا و قابل استفاده دوباره است (مثلا ProjectCard هم در خانه و هم در پروژه‌ها).
- **useState و useEffect:** زبان سایت با `useState` نگهداری و در localStorage ذخیره می‌شود؛ پروژه‌های گیت‌هاب با `useEffect` و `fetch` از API گیت‌هاب می‌آیند.
- **دو زبانه (i18n ساده):** همه متن‌ها در یک آبجکت `TEXT` هستند و با عوض شدن زبان، جهت صفحه (rtl/ltr) هم عوض می‌شود.
- **ریسپانسیو:** با CSS Grid و media query برای موبایل، تبلت و دسکتاپ.
- **دسترسی‌پذیری:** متن جایگزین (alt) برای عکس‌ها و aria-label برای آیکون‌ها، و احترام به `prefers-reduced-motion`.
- **داده جدا از ظاهر:** برای تغییر محتوا لازم نیست کامپوننت‌ها را دست بزنید.
